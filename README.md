# 🔐 Face Login System using AI/ML

A secure face-based authentication system using Python, OpenCV, and `face_recognition`. This project captures user faces via webcam, generates face embeddings, and allows login by verifying real-time webcam input against registered embeddings.

---

## 🚀 Features

- ✅ Real-time face detection via webcam
- ✅ Face embedding and recognition using deep learning (`face_recognition`)
- ✅ Register new users with a single key press
- ✅ Fast, accurate login with identity match
- ✅ Lightweight, works offline
- 🧩 Easily extensible: add liveness detection, mask detection, or GUI

---

## 🛠️ Tech Stack

- **Python 3.8+**
- **OpenCV** – webcam integration
- **face_recognition** – face detection & matching (built on dlib/FaceNet)
- **NumPy** – data handling
- *(Optionally)*: Streamlit/Flask for web UI
